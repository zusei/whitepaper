# 04.2 ZConnect Hardware: The Truth Oracle

**Focus:** The Physical-Digital Bridge  
**Key Component:** Dynamic Edge Verification

---

## The Hardware Philosophy: "Any Device as a Sensor"

For Zusei to scale to thousands of nodes in Singapore without massive capital expenditure, we cannot require proprietary mining rigs for every location. The **ZConnect Protocol** is designed to be **Sensor Agnostic**.

We turn existing device infrastructure into "Truth Oracles" using two integration tiers:

### Tier 1: ZConnect Lite (Software Edge)
**Target:** SMEs, Pop-up Stores, Cafe Chains  
**Hardware:** Any existing iPad, Android Tablet, or POS Screen.  
**Mechanism:** The merchant installs the **Zusei Terminal App**. It turns their screen into a **Dynamic Verification Surface**, generating the visual TOTP codes required for Proof of Presence.
* **Trust Score:** Standard.
* **Cost:** $0 (Software only).

### Tier 2: ZConnect Pro (Hardware Oracle)
**Target:** High-Volume Retail, Smart City Infrastructure, Franchises  
**Hardware:** A dedicated, low-power IoT device (ESP32 / Raspberry Pi Zero) with an e-ink or OLED display and a Secure Element (SE) chip.  
**Mechanism:** Hardwired to the shop’s power. It broadcasts **BLE (Bluetooth Low Energy) beacons** alongside the visual QR code for dual-layer verification.
* **Trust Score:** Premium (Higher Data Quality = Higher Mining Rewards).
* **Cost:** ~$50 USD.

## The Engine: The Cryptographic Heartbeat

The core security of the ZConnect Node is powered by a lightweight, server-synced script (e.g., `print_qr.php` or Python equivalent). This script functions as the "Heartbeat" of the location, proving liveness.

### 1. The Generation Logic
Unlike a static URL (e.g., `zusei.com/shop/starbucks`), the ZConnect Node generates a **Cryptographic Puzzle** that changes every 15 seconds. If a user scans an old code, the consensus engine rejects it as a "Replay Attack."

**The Core Algorithm (Simplified PHP Logic):**
```php
// 1. Define the Time Window (15 Seconds)
$timestamp = floor(time() / 15); 

// 2. Add Entropy (Prevent Prediction)
$nonce = random_bytes(8); 

// 3. Sign the Payload (HMAC-SHA256)
// This proves the code was generated by THIS specific Merchant Node
$payload = hash_hmac('sha256', $merchant_id . $timestamp . $nonce, $secret_key);

// 4. Construct the Deep Link
// When scanned, this opens the User's Mining App directly
$qr_content = "zusei://" . $merchant_id . "/" . $payload . "?ts=" . $timestamp;

// 5. Render QR to Screen
echo generate_qr($qr_content);
